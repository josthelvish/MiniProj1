# Tarefa 2.2 — Mini-Projeto 1: Currículo Vitae em SPA

Repositório dedicado ao desenvolvimento do **MiniProj1** no âmbito da unidade curricular, com foco na consolidação de páginas HTML e introdução ao conceito de **Single Page Application (SPA)**.

---

## 📌 Descrição do Projeto

Esta atividade corresponde ao primeiro desenvolvimento web da unidade curricular. O objetivo principal é verificar e consolidar conhecimentos prévios de marcação HTML e estilização, integrando a arquitetura de **Single Page Application (SPA)**.

### O que é uma SPA?
Uma **Single Page Application (SPA)** é uma aplicação ou website contido numa única página web, desenhada para proporcionar uma experiência de utilização fluida e semelhante à de uma aplicação nativa/desktop.
* **Carregamento inicial:** Os recursos essenciais (HTML, JavaScript, CSS) são carregados de uma só vez ou agregados sob demanda.
* **Navegação interna:** A transição entre secções ocorre dinamicamente por meio de links internos, âncoras ou janelas modais, sem necessidade de recarregar a página inteira no navegador.

---

## 🎯 Estrutura e Requisitos da Aplicação

O projeto consiste num **Currículo Vitae** pessoal, centrado no ficheiro `index.html`.

### Secções Obrigatórias:
- **Quem Sou Eu?**
  - **O que faço?**
  - **Hobbies**

### Rodapé (Footer):
- Deve conter a **identidade virtual** do autor.
- Incluir ícones com hiperligações para perfis de redes sociais populares (ex.: *LinkedIn, GitHub, X/Twitter, Facebook, etc.*).
- O rodapé deve estar visível e consistente em toda a experiência de navegação.

### Tecnologias Permitidas:
- **Frameworks:** [Vue.js](https://vuejs.org/)
- **HTML5 & CSS3**
